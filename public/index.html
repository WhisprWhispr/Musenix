🎧 Pusat Bantuan MUSENIX

🤖 Panduan Instalasi Android (APK)

1. Unduh berkas MusenixMusical-1.0.0.apk melalui tombol unduh Android.

2. Jika muncul peringatan sistem "File mungkin berbahaya", pilih Tetap Download atau Buka. Hal ini wajar untuk file APK yang diinstal di luar Google Play Store.

3. Aktifkan izin "Pasang aplikasi tidak dikenal" pada browser Chrome atau File Manager Anda.

4. Buka aplikasi, login atau masuk langsung untuk mulai memutar lagu!

🍏 Panduan Instalasi iOS (iPhone & iPad)

1. Buka tautan di browser Safari, lalu unduh profil WebClip Profile (.mobileconfig).

2. Buka Pengaturan iPhone > Profil Diunduh > Tekan Pasang.

3. Atau gunakan berkas MusenixMusical-1.0.0.ipa dengan aplikasi sideload tepercaya seperti AltStore, Sideloadly, atau Scarlet.

🎤 Mode Karaoke & Lirik Berjalan

• Ketuk ikon Mikrofon/Karaoke pada pemutar lagu penuh untuk menghilangkan vokal penyanyi dan hanya menyisakan instrumen musik.

• Buka tab Lirik untuk membaca lirik sinkron yang bergulir otomatis per detik. Ketuk baris lirik mana pun untuk melompat ke detik tersebut.

💚 Cara Import Playlist Spotify

• Buka tab Library di aplikasi MUSENIX Musical.

• Ketuk tombol Import dari Spotify, tempelkan URL playlist publik dari aplikasi Spotify Anda, lalu tekan Import Playlist.

• Seluruh lagu dalam playlist akan otomatis dicocokkan dan siap diputar di MUSENIX.
